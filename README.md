# WB小灯（V2.7）

macOS 菜单栏状态灯：**WorkBuddy 干活时，你不用盯着屏幕也知道它在不在忙。**

## 灯语

- **忙**：菜单栏绿色加粗 `W`，闪烁；面板显示「当前任务：xxx · 工作中 · 已忙 X 分 X 秒」
- **闲**：红色加粗 `W`，常亮，显示「闲置中」
- 忙闲判定读本机会话日志（transcript），含深度思考（reasoning）阶段——思考时也算忙
- 15 分钟无动静自动判定停止，杜绝"活干完了灯还闪"

## 积分余额

菜单栏显示为 `W 5508` —— 绿色数字是 WorkBuddy 积分余额，60 秒刷新：

- 数据源：`codebuddy.cn` 账单接口（复用本机积分助手的登录态，灯本身不碰 token）
- 失败时保留上次真实值（宁旧勿假）；从未成功就只显示 `W`

## 安装

1. 从 [Releases](../../releases) 下载 zip，解压，把 `WB小灯.app` 拖进「应用程序」
2. **首次打开**：未做 Apple 公证，先右键 → 打开（详见包内 `首次打开必读.txt`）
3. 运行依赖：本机已使用 WorkBuddy（有 `~/.workbuddy/` 目录）；查积分余额需能访问 codebuddy.cn

## 编译

```bash
clang -fobjc-arc -framework Cocoa -o WBLight 源码/WBLight.m
```

macOS 自带 clang 即可，零第三方依赖。通用二进制（arm64 + x86_64）。
