# WB小灯（V2.7）

macOS 菜单栏状态灯：**WorkBuddy 干活时，你不用盯着屏幕也知道它在不在忙。**

## 灯语

- **忙**：菜单栏绿色加粗 `W`，闪烁；面板显示「当前任务：xxx · 工作中 · 已忙 X 分 X 秒」
- **闲**：红色加粗 `W`，常亮，显示「闲置中」
- 忙闲判定读本机会话日志（transcript），含深度思考（reasoning）阶段——思考时也算忙
- 15 分钟无动静自动判定停止，杜绝"活干完了灯还闪"

## 积分余额

菜单栏显示为 `W 5508` —— 绿色数字是 WorkBuddy 积分余额，60 秒刷新：

- 数据源：`codebuddy.cn` 账单接口（复用本机积分助手的登录态，灯本身不碰 token）
- 失败时保留上次真实值（宁旧勿假）；从未成功就只显示 `W`

## 面板

```
当前任务：xxx            ← 第一行，绿字
工作中 · 已忙 3 分 12 秒  ← 第二行（闲 =「闲置中」）
────────────────
今日消耗：xxx 积分
────────────────
测试网速
更换提示音 ▸             ← 16 个音源，点音名即试听并设为当前
关于 WB小灯 ▸            ← 版本 / 项目主页 / 问题反馈
────────────────
重启 WB小灯 🔄
退出 WB小灯 ⊠
```

## 安装

1. 从 [Releases](../../releases) 下载 zip，解压，把 `WB小灯.app` 拖进「应用程序」
2. **首次打开**：未做 Apple 公证，先右键 → 打开（详见包内 `首次打开必读.txt`）
3. 运行依赖：本机已使用 WorkBuddy（有 `~/.workbuddy/` 目录）；查积分余额需能访问 codebuddy.cn

## 运行依赖

- 读取本机 WorkBuddy 会话事件日志（transcript）判断忙闲：`~/.workbuddy/projects/<项目>/<会话id>.jsonl`
- 读取 WorkBuddy 侧栏快照取「当前任务」标题
- 查积分余额/今日消耗：调 `codebuddy.cn` 账单接口，复用本机「积分助手」技能的登录态（灯本身不碰 token）
- 需要能访问 `codebuddy.cn` 的网络环境
- macOS 11+（菜单图标用 SF Symbols）

> **「今日消耗」的口径**（易混淆，写在这里）：按**自然日**（本机时区 0 点）算，
> 但基线锚定在「当天灯第一次成功取到数据的时刻」——灯全程开着跨天 = 准的自然日；
> 灯半夜才启动 = 0 点到启动那一段不计入，数值偏小不偏大。
> 「今日调用」数的是 WorkBuddy 审计事件行数，不是模型调用次数（一次工具调用约 2~3 条事件）。

## 编译

```bash
clang -fobjc-arc -framework Cocoa -o WBLight 源码/WBLight.m
```

macOS 自带 clang 即可，零第三方依赖。通用二进制（arm64 + x86_64）。

> 版本号唯一来源：源码顶部 `static NSString * const kAppVersion`，菜单「关于 WB小灯 → 版本 x.y」从这里读。
> 升版时改这一处，同时用 `plutil` 同步 `Info.plist` 的 `CFBundleShortVersionString` / `CFBundleVersion`；
> 以 `WBLIGHT_DEBUG=1` 启动时会自动比对，不一致打印 `⚠️ 版本不一致，请同步！`。
